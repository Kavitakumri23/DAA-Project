# Design and Analysis of Algorithms (DAA) Project

## 📌 About the Project

This project focuses on the practical implementation of concepts studied in Design and Analysis of Algorithms (DAA). It demonstrates how algorithms can be used to solve computational problems efficiently using Python.

The project aims to connect theoretical concepts with practical implementation, making it easier to understand algorithm behavior, execution, and performance.

## 🎯 Objectives

* Implement algorithmic concepts using Python.
* Understand the step-by-step working of algorithms.
* Analyze time and space complexity.
* Evaluate algorithm performance for different inputs.
* Apply problem-solving techniques to computational problems.

## 📊 Algorithm Analysis

The project considers algorithm efficiency through:
The project uses Dijkstra's Algorithm to find the shortest path between nodes in a network.

* **Time Complexity:** `O((V + E) log V)` when using an adjacency list and a binary heap priority queue.
* **Space Complexity:** `O(V + E)` for storing the graph and the additional data structures used by the algorithm.

Where:

* `V` represents the number of vertices (network nodes).
* `E` represents the number of edges (connections between nodes).
